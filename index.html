Protocolo de Trabajo en Google NotebookLM

Fase 0: Búsqueda de Fuentes y Assets en la Web

Localización de Imágenes de Acceso Abierto en Wikimedia Commons

En su cuaderno de Google NotebookLM, acceda a + Añadir fuentes > Buscar fuentes en la Web y pegue la siguiente instrucción para obtener enlaces directos a imágenes:

Busca imágenes y recursos visuales en Wikimedia Commons y repositorios de dominio público sobre [TEMA O PERSONAJES, ej: Benito Pérez Galdós / Sistema Solar / Ecosistemas Canarios].
Requisitos:
1. Necesito URLs directas y completas a imágenes (.svg, .png o .jpg), preferiblemente alojadas en upload.wikimedia.org.
2. Identifica un retrato o figura en plano recortado para el personaje principal (Sprite).
3. Identifica una imagen panorámica o escena de fondo para el escenario (Backdrop).
4. Presenta el resultado en una tabla con tres columnas: Elemento (Personaje/Fondo), Descripción pedagógica y URL directa de la imagen.
Fase 1: Guion Didáctico e Instruccional

Estructuración de la Secuencia Didáctica

Pegue esta instrucción en el chat de consultas de NotebookLM para estructurar la situación de aprendizaje o narrativa:

Actúa como un Asesor Pedagógico experto en Tecnología Educativa. A partir de las fuentes analizadas en este cuaderno, diseña la estructura completa de un proyecto interactivo en Scratch 3.0 sobre este tema.
Estructura la propuesta en:
1. Justificación Curricular y Saberes Básicos.
2. Personajes participantes y fondo de escenario (vinculando las URLs obtenidas en la Fase 0).
3. Secuencia en al menos 15 intervenciones (diálogos, desplazamientos y al menos 2 preguntas interactivas tipo quiz con retroalimentación para el alumnado).
Fase 2: Generación del JSON para el Compilador

Master Prompt de Conversión Determinista

Solicite a NotebookLM la entrega del JSON listo para copiar en esta herramienta:

Basándote en el guion didáctico y las fuentes del cuaderno, genera el código JSON para la herramienta Scratch Compiler Tool (prompt-to-sb3).

REGLAS TÉCNICAS OBLIGATORIAS:
1. Devuelve ÚNICAMENTE el bloque de código JSON crudo (sin texto explicativo previo ni posterior).
2. Utiliza exactamente las URLs directas identificadas en la Fase 0 para 'backdrop' y 'costumes'.
3. Formato requerido:
{
  "name": "Nombre_Del_Proyecto",
  "backdrop": { "name": "Nombre_Fondo", "url": "URL_DIRECTA_FONDO" },
  "costumes": [
    { "name": "Nombre_Personaje", "url": "URL_DIRECTA_DISFRAZ" }
  ],
  "variables": { "puntos": 0 },
  "actions": [
    { "type": "start" },
    { "type": "move", "x": 0, "y": -40 },
    { "type": "say", "text": "¡Saludos! Sean bienvenidas y bienvenidos.", "seconds": 3 },
    { "type": "wait", "seconds": 1 },
    { "type": "ask", "question": "¿Pregunta interactiva?", "answer": "Respuesta", "correct_say": "¡Exacto!", "incorrect_say": "No es correcto." }
  ]
}
Fase 3: Apertura y Ejecución en Scratch

Cargar el Archivo .sb3 Descargado

1. Pulse el botón Compilar y Descargar .sb3 en la pantalla principal.

2. Abra el editor en línea de Scratch (scratch.mit.edu/projects/editor) o abra Scratch Desktop.

3. En el menú superior izquierdo, seleccione Archivo > Subir desde tu ordenador y elija el archivo descargado.
